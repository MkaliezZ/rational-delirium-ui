# 来源与版本覆盖检查

当前状态题在生成前读取 `source_coverage`，在交付前按原始 `questions` 再次计算覆盖清单。单条精确引用不足以证明已检查同项目的其他记录。

覆盖从案例及正式入链证据的声明来源开始，包含同仓库、会话或文档的其他已保存快照。版本按明确仓库或 `rd_version_family` 分组；来源中的当前声明与历史记录分别保留。抓取、复核、会话日志文件日期和版本大小都不建立事件或发布先后。没有显式来源事件日期时保持 null。

当前和历史版本的必要原文、不同来源记录覆盖、结构化版本对照与正文版本描述均进入宿主检查。范围不明确、来源缺失、清单截断或当前声明冲突时不能发布确定当前状态；可保留明确未知与具体缺口。未知正文由宿主规范化，回执在同一资料版本下重复核对保持稳定。

## 工程验收

- 704 项 Vitest，65 个测试文件；62 项 Python 检查通过。
- 类型、插件和独立运行包构建、隔离运行包检查、既有合成检索/角色评估通过。
- 新回归覆盖漏引新版、遗漏历史版本、只有元数据没有正文版本、同源摘录重复计数、未引用新快照、冲突声明、依赖版本隔离、资料在生成期间变化、原问题缺失与回执重复核对。
- 实际默认只读 MCP 与本地 HTTP 均验证新版及历史版本遗漏被阻止、未知正文撤回、只读及回执稳定。故障注入和 provider stub 只用于工程检查，不作为模型回答得分。

## 适用边界

项目范围和版本声明识别依赖已声明身份、词法匹配及明确的来源文本；它不提供联网同步、穷尽所有事实或语义真理证明。未联网核验的远端当前状态始终 unknown。记录数量不等于独立实验数量。工具对齐检查与人工复核正文范围分别报告。

实际 DSH 复测使用私有冻结材料和既有 14 个真实问题，不是新的盲测集；不把答案、评分或此前模型输出提供给被测 Agent。私有材料与完整模型记录保存在知识库外，未进入此仓库。

## 实际 DSH 结果

- 安装版本 0.2.0-rc.2，固定运行包与 260 份原始 Markdown，完整运行 14 题、7 组。
- 77/77 条引文与原文对齐且出现在实际提供的上下文中；23/23 条正式关系匹配声明，答案的 2 条候选仍单列。
- 7 题检查当前状态覆盖；其中 2 题因跨项目同一性或当前商业结果不足保留覆盖未知，不计为获得实质性当前状态结论。
- 2 份初稿退回、2 轮同会话修正；没有失败兜底。新版与历史发布声明同时进入目标答案，远端当前状态仍未知。
- 153 次读取入口调用出现 16 次参数/范围错误与 14 次预算拒绝，均保留记录。
- 7 份最终回执重复核对一致。人工另行复核 14 题关键边界，保留日志日期精度与说话人归属的措辞提示；这不等于全部语义或真实世界状态已证实。
- 评估期间原知识库、原始归档、文档及 4 条库中候选保持不变。测试后仅保存报告与首页入口。

早期集成运行在发现回执缺口重复追加问题后停止，诊断记录保留但不计入本轮完整结果；修复并加入重复核对回归后重新固定运行包复测。
