# 按版本复用检索预处理

2026-11-07 的真实材料整理中，增加工作区内的检索预处理缓存。未变化的文件复用分词与词频；正文版本、对象身份、标题或检索范围变化时重新准备，删除文件时清理缓存。查询仍核对磁盘，并按原来的相关性算法排序。

两项新增回归检查了源文件更新、标题更新、正文/标题范围隔离、独立工作区和缓存清理。完整 `npm run validate` 通过：59 个 TypeScript 测试文件、657 项测试，以及 62 项 Python 测试，共 719 项。固定检索和角色语料评估保持通过。后续状态中文映射调整再次通过类型检查、独立运行时构建和隔离产物检查。

同时补充旧格式假设的 `refuted`、`open`、`closed`、`supported` 中文状态。界面把反驳/支持表述为已有记录，不以记录数量代替内容判断。

个人来源、整理后的知识文件和私有验收材料保存在产品仓库之外。真实材料的引用完整性检查与检索抽查不代表所有内容的真实性或模型回答质量；没有重跑被引用项目的历史实验。
