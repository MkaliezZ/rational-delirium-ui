# 案例分卷与关系路径

2026-11-07，在现有独立网页结构上优化案例索引和四角色关联展示。沿用深色档案风格与橙红强调色。

## 案例索引

案例按已声明的 `rd_case_group` 分卷；没有自定分组时，按已有 `rd_importance: A/B` 展示重点/参考案例，其余进入普通案例卷。没有根据标题猜测领域，也没有回写分组。选中案例展开简介和直接连接的 E/H/L 单元数，保留普通搜索结果的相关性顺序。

`boards.caseIndex` 是只读投影，提供分组、重要性、正文简介、直接角色覆盖和声明数。多角色邻居在各自角色下计数，同一角色内按身份去重。两步外的反例不计作案例自身的直接反驳。

## 关系路径

关联视角按支持、反驳、补充/上下文组织具名、有方向的声明。每段关系可以打开原始声明的路径、字段、行号和版本；点击知识单元可继续以它为中心展开。角色和路径类型可以组合筛选。

路径保留中间知识和原始方向，不推导传递性的支持或反驳。相同单元之间的不同关系均保留；上下文中其他单元之间的声明独立标注。每条载入的有效声明至少在一条可展开的路径中可达。范围沿用深度 2、最多 32 个单元及 128 条声明；预算截断和待解析目标会显示。

普通正文、知识身份、原文引用和知识包格式不变。假设完整正文和循环模式的跨案例对照继续可读。URL 保存正文/关联视角，沿路径切换中心、浏览器返回和刷新可以恢复关联视角。
