# 独立网页的页面结构调整

2026-11-07，针对真实材料入库后的导航、阅读与来源核对进行适度重构。保留现有暗色档案视觉、橙红强调色、四角色和数据接口。

## 最终结构

1. **进入知识**：知识总览展示实际角色计数与案例入口；左侧分开浏览、材料收集、内容索引和折叠的管理入口。索引以标题为主，完整 ID 仍能搜索和复制。
2. **阅读材料**：正文与关联知识分开切换。长文提供可用键盘操作的目录；本轮导入包装中的来源信息与内嵌元数据仅在展示层折叠，存储原文和引用行号不变。
3. **核对关系与来源**：检查器按需展开，关闭后不留在键盘访问路径中，支持 Escape 和焦点返回。路径、版本和引用保留；笔记摘录默认折叠。关联组超过五条时，可明确展开其余内容。

## 验证

- 完整 `npm run validate` 通过：60 个 TypeScript 测试文件、661 项测试，另有 62 项 Python 测试，共 **723 项**；类型、构建、插件产物、隔离运行和固定检索/角色评估通过。
- 新增四项回归：导入包装与普通正文的区分、总览真实数据及 HTML 转义、超过五条关联仍全部可达、实际网页应用的阅读/关系/来源/总览往返。
- 收尾的来源摘录折叠与长引用换行再次通过类型检查、四项网页回归、独立构建和隔离产物检查，并实测手机检查器。
- 浏览器检查：默认桌面、1440×1000 与 390×844。总览进入案例、搜索、返回、目录定位、来源面板开合与焦点返回、关联余项展开、历史假设的反驳记录和完整正文均可用。窄屏打开来源面板后，文档与面板均未横向溢出。临时视口设置已恢复。
- 减少动态效果沿用既有偏好控制，相关回归通过；没有进行完整的屏幕阅读器或 WCAG 合规验收。
