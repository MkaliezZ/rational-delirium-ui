# Dossier layout · v1.11.0

The reference is [the user's earlier dossier](dossier-ui-reference.png). This correction aligns layout and actual function entries: shared left directory, central reading desk and persistent desktop inspector, using the already selected warm red/orange direction.

| Reference intention | Product mapping |
| --- | --- |
| Home, graph and all notes | Overview, directed relationship exploration and asset library |
| Four available folders | CASE/EVIDENCE/HYPOTHESIS/LOOP, real counts, selection and reachable overflow |
| Document strip/title | Document context, roles, declared status, source/relation/candidate counts |
| Properties/backlinks/graph | Properties, relationships and source tabs, direction, excerpts and origin/version details |
| Evidence alongside observations | Exact citations, directed paths and separate candidate gaps |
| Material organization | Manual capture and explicit-scope Agent intake configuration |
| Revision/recovery | Visible proposal/history/import-export entries and reviewed transaction recovery |

Fictional confidence percentages and verification dates are not generated for real notes. Source-match counts describe saved versions. Existing directed paths remain the graph interaction; no dot cloud was added. Trash, stars, native window chrome and decorative illustrations are not presented as working capabilities in this change.

The browser downloads scope JSON; a local Agent executes intake with its configured model/adapter. Configuration and execution are described separately. The page does not silently scan local files or launch a provider.

Desktop uses three columns above 1120px; narrow layouts use explicit directory/source drawers. Existing reading transitions and small folder changes honor reduced-motion preferences. [QA](../../design-qa.md) records comparison and interaction evidence.
