# Rational Delirium v1.7.0 — Archive Home Experience

Rational Delirium is an Obsidian plugin for human-governed knowledge organization. This checkpoint establishes an Archive Home entry experience on the existing RD Workspace and stabilizes its lifecycle during Obsidian layout restoration.

- **Tag:** `v1.7.0-archive-home-experience`
- **Target commit:** `3d542ff22e9fd8e309201546b6609b54302dd60d`
- **Release scope:** the frozen plugin checkpoint; subsequent documentation does not retarget the tag.

## Major features

- **Archive Home:** a landing state inside RD Workspace, presenting declared objects, existing collaboration records, relations, unresolved declarations, and snapshot diagnostics.
- **Rational Archive shell:** Archive Navigator, central Workspace, and Inspector in actual Obsidian leaves.
- **Knowledge Object Surface:** identity, provenance, relations, and lineage alongside native Markdown and Properties.
- **Graph Intelligence:** declared relationship exploration with direction, source context, and provenance-preserving navigation.
- **Native integration:** existing Markdown, Live Preview, ordinary notes, and host navigation remain available.

The shell, Knowledge Object Surface, and Graph Intelligence are included capabilities of the baseline; they were not all newly introduced by the Archive Home change.

## Lifecycle stabilization

Shell activation now waits for Obsidian layout readiness before supplying missing dock leaves. Explicit view activation also waits for restoration. Deferred Markdown leaves without a file are handled without dereferencing an unavailable path; stale asynchronous work is discarded when its view is no longer current.

## Architecture guarantees

- Markdown remains the source; graph state is derived presentation, not authority.
- Home reuses the shared Workspace snapshot and Collaboration browser. It adds no ItemView, database, index, or loader.
- Graph Intelligence and Workspace retain their distinct data contracts.
- No schema, relation semantics, provenance semantics, Agent Skill, Bridge, or Mutation Gate change is included in the Home milestone.
- No confidence scoring, inferred relationships, AI recommendations, or automatic approval is introduced.
- Human decision recording remains separate from knowledge execution. A contribution record is reported provenance, not independent verification.

## Installation and usage recommendation

Start with a copy of an existing Vault. Obtain `main.js`, `manifest.json`, `styles.css`, and `tokens-rational-archive.css` from this tag's `dist/`, or build this exact tag with `npm ci` and `npm run build`. Copy all four into `<vault>/.obsidian/plugins/rational-delirium/`, enable the plugin, and run **Open RD Workspace**.

This is a manual desktop installation checkpoint. The frozen manifest requires Obsidian 1.13.7 or later and still reports plugin version **0.4.4**. The **v1.7.0** tag identifies the release checkpoint; no manifest or runtime file was changed for this documentation preparation.

Use external agents for proposals and traceable contributions under the bundled Skill and explicit Human review. The Skill grants no permissions; its default workflow uses Human apply. RD does not run agents or execute approved knowledge modifications.

## Known boundaries

- Snapshot-dependent Workspace views need `semantic-graph/graph.json`; the plugin does not generate or repair it.
- Missing snapshot does not mean empty knowledge and does not block Collaboration.
- Loaded snapshots are not automatically verified as fresh.
- Unresolved declarations and diagnostics describe recorded structure, not correctness.
- The legacy `npm run check-artifacts` script still expects three distribution files and rejects the existing fourth token stylesheet. It was not a passing validation gate; the build and runtime checks above are separate results.
