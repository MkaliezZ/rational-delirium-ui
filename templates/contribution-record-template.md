     A contribution record records THAT a contribution happened —
     who, what, why, on what evidence, when. It does NOT prove

     never edit submitted records (corrections are new records).

# Contribution Record

## Metadata

- contribution_id: CONTRIB-YYYYMMDD-NNN
- author_agent: "<declared agent name / host / role>"
- created_at: "YYYY-MM-DDTHH:MMZ (state the clock basis if known)"
- related_proposal_id: "<PROP-… this contribution records, or null>"
- related_proposal_decision: "<approved | rejected — the recorded Human decision on that proposal, if any>"

## Contribution Summary

What was contributed?

## Evidence Used

What sources informed this contribution? (attributed, with
acquisition context; inference labeled as inference)

## Change Description

What was proposed or applied? (applied changes are Human-performed;
this section records what happened, not permission)

## Human Decision

Human review outcome. (recorded decision + scope; "none yet" is a
valid state — silence is not a decision)

## History

Append-only notes. (each note: date + one line; never rewrite or
remove earlier notes)
