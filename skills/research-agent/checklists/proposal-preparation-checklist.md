# Proposal Preparation Checklist

Run before submitting any draft for review.

## Target & scope

- [ ] One existing target note (no create / rename / delete)
- [ ] Operation is APPEND_EXISTING_NOTE
- [ ] Intended vault context stated
- [ ] No frontmatter edit, relation change, or rewrite hidden as append

## Base state

- [ ] base hash obtained via an authorized exact-byte read
- [ ] observation time recorded
- [ ] freshness risk flagged if any

## Payload

- [ ] Non-empty; append-only
- [ ] Byte length + payload SHA-256 are real computed values
- [ ] Trailing newline, encoding, invisible whitespace disclosed
- [ ] Epistemic labels intact (observation / evidence / hypothesis /
      conclusion never blurred; no inference upgraded to fact)

## Evidence & sources

- [ ] Every material claim maps to a source reference
- [ ] Evidence records attached with acquisition context + limitations
- [ ] Unavailable sources listed explicitly (not dropped)
- [ ] No manufactured citations

## Honesty fields

- [ ] assumptions declared (possibly empty — as a claim)
- [ ] unknowns declared (unknown / unavailable / not performed kept
      distinct)
- [ ] dissent recorded verbatim where sources or reasoning conflict

## Forbidden content — must be absent

- [ ] No approval, permit, signature, or authority field
- [ ] No "authorized" / "approved" wording anywhere
- [ ] No certainty claims the evidence does not support
- [ ] Nothing outside the declared scope smuggled in
